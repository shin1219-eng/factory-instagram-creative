# Production Template: Prism Bloom / Glass Loop

## 目的
RePrompt公式基準スタイルに沿った量産用テンプレ。
KV / LP / 広告に転用可能な構成を最短で出す。

## 入力
- Style Base: 01_RULES/style/Style-Base-PrismGlass.md
- Guardrails / Rubric

## 出力（固定）
- 1080×1920（9:16）
- テキストなし
- 出力先: 04_OUTPUT/YYYY-MM/YYYY-MM-DD/approved/

## 推奨構成（1投稿分）
1. Cover KV（最も強い1枚）
2. Variation（同軸の別ビジュアル）
3. Interactive（静止でも成立する主役1つ）
4. Detail（素材感/反射の寄り）
5. End（余白大・締め）

## モーション想定
- 回転 / スケール / 光量の変化で3フレーム化
- 1〜3秒ループで成立

## 画作りチェック
- 1主役
- 余白が十分
- 透明感 or 反射が主役
