# Style Base: Prism Bloom / Glass Loop（RePrompt公式 基準スタイル）

## 目的
RePrompt公式の基準スタイルを「Prism Bloom / Glass Loop 系」で固定する。
高級・先端・無機質を担保し、量産投稿・KV/LP/広告への転用を前提にする。

## キーワード
- 高級 / 先端 / 無機質
- 透明感 / 発光 / 反射
- 1主役 / 広い余白 / 低ノイズ

## 形式（固定）
- サイズ: 1080×1920（9:16）
- テキスト: なし（後工程で載せる）
- 主役: 1つ
- 背景: 暗色〜中間色のグラデ（黒ベース推奨）

## 形状・素材
- Prism Bloom: プリズム的な発光体（多色グラデ）
- Glass Loop: ガラスリング（反射＋薄い縁）
- 質感は「透明感」or「反射」を主役にする

## 構図
- 中央やや上寄せ（視線が止まりやすい）
- 余白は上下広め、主役は1つに固定
- 影は薄めだが存在感のある密度で

## カラー
- 基本: 黒〜濃紺背景 + 1アクセント（寒色/発光系）
- 彩度は高すぎない（高級感維持）

## モーション展開
- 回転・スケール・光量変化の3パターン
- 1〜3秒のループでも成立する構成

## NG
- 文字多い、情報過多
- 主役が2つ以上
- 暖色主体・装飾過多
- 既存ブランドの固有意匠
